# doraft-plugins

Doraft 제품의 AI 플러그인 카탈로그다. 플러그인 **원본은 각 제품 저장소**에 두고, 이 저장소에는 릴리스만 반영한다.

지금은 private다. 카탈로그를 공개할 때 공개 저장소로 바꾼다(위키 「작업 계획」 F1).

## 상태

2026-09-22 생성. 아직 반영한 플러그인이 없다.

| 플러그인 | 원본 | 상태 |
| --- | --- | --- |
| `doraft-wiki` | `doraft-labs/doraft-workspace`의 `packages/doraft-integrations` | 반영 전 |
| Notes 플러그인 | `doraft-labs/doraft-notes` | 계획 |

## 규칙

- 제품마다 플러그인을 따로 만든다. Wiki 플러그인과 Notes 플러그인을 하나로 합치지 않는다.
- 이 저장소에서 플러그인 코드를 직접 고치지 않는다. 제품 저장소에서 고치고 릴리스를 반영한다.

기획·설계의 정본은 [Doraft Wiki](https://wiki.doraft.com/w/0rhp3csshy8qm/pages/0rj0r3j2dmysa)다.
