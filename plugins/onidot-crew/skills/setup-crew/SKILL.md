# setup-crew

이 스킬은 Codex 전용이다. Claude Code는 플러그인을 설치하면 역할이 함께 등록되므로 필요 없다.

Codex는 플러그인 안의 에이전트 정의를 자동으로 읽지 않는다. 역할 정의(`crew-<역할>.toml`)를 사용자의 Codex 설정 디렉터리(`~/.codex/agents/`, `CODEX_HOME`이 있으면 그 아래)에 놓아야 한다. 놓는 일은 플러그인 디렉터리의 `scripts/codex-agents.mjs`가 한다.

## 순서

1. 플러그인 디렉터리에서 `scripts/codex-agents.mjs`를 찾는다. 이 스킬이 있는 디렉터리의 두 단계 위가 플러그인 루트다.
2. `node <플러그인 루트>/scripts/codex-agents.mjs status`를 실행한다. 파일마다 `설치됨 / 최신 아님 / 없음`이나 충돌 상태(`충돌(사용자 파일)`·`충돌(링크)`·`충돌(이름)`)와 기록된 버전이 나온다. 충돌 파일은 덮어쓰지 않는다.
3. 결과를 바탕으로 무엇이 바뀔지 사용자에게 알린다. 새로 놓을 파일, 교체할 파일, 충돌 파일을 구분해 말한다.
4. 사용자 설정을 바꾸는 일이므로 install·uninstall 전에 사용자 확인을 받는다. 확인 없이 실행하지 않는다.
5. 확인을 받으면 `install`(또는 `uninstall`)을 실행하고 출력을 그대로 전한다.

`--codex-home <dir>`로 대상 위치를, `--json`으로 기계 판독 출력을 고를 수 있다.

## 충돌

대상에 같은 이름의 파일이 있는데 이 도구가 놓은 것이 아니거나 사용자가 고쳤으면 충돌이다. 충돌 파일은 덮어쓰지 않는다. 어떤 파일인지 사용자에게 알리고, 옮기거나 이름을 바꾼 뒤 다시 실행할지는 사용자가 정한다. 충돌이 있어도 나머지 파일은 설치된다.

## 설치 뒤

실행 중인 Codex 세션은 역할 목록을 다시 읽지 않는다. Codex를 새 세션으로 열어야 한다. 확인은 새 세션에서 `crew-explorer` 같은 역할을 불러 보거나 `status`가 모두 `설치됨`인지 보면 된다.

## 제거

`uninstall`은 이 도구가 놓은 그대로인 파일만 지운다. 사용자가 고친 파일은 남기고 그 사실을 출력한다.
